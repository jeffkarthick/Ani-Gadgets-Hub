# ANI Gadgets Hub — Static Website

A responsive storefront landing page built from the supplied ANI Gadgets Hub Instagram screenshots.

## Run locally
Open `index.html` in a browser, or deploy the folder to Vercel / Netlify / GitHub Pages.

## Edit products
Open `index.html` and update product names, descriptions and prices.

## WhatsApp
The order buttons currently use +91 63804 55880 based on the supplied Instagram screenshot. Change it in `index.html` and `script.js` if needed.

All website UI copy is in English.
